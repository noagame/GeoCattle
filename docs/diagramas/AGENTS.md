# Diagramas del informe

## Propósito y alcance

Aquí se mantienen las fuentes PlantUML y las figuras SVG y PNG de componentes, despliegue y modelos de datos.

## Contratos locales

- Mantén las exportaciones alineadas con sus fuentes. Cuando una migración cambie tablas o relaciones, regenera el mapa completo con `generar_modelo_bd.py` desde el catálogo de una base migrada. El generador consulta solo el catálogo.

## Verificación

Regenera y renderiza las fuentes con los comandos del [README](README.md).
