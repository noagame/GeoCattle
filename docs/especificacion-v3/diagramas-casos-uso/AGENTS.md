# Diagramas de casos de uso V3

## Propósito y alcance

`catalogo_diagramas.json`, las fuentes PlantUML, el archivo Draw.io y las exportaciones PNG y SVG representan los diagramas que enumera el [README](README.md).

## Guía de trabajo

Al modificar actores, relaciones o nombres, comprueba su correspondencia con [los casos de uso](../01_CASOS_DE_USO.md). Conserva sincronizadas las representaciones afectadas usando `generar_diagramas.py` cuando corresponda.

## Verificación

Sigue las comprobaciones de [VALIDACION.md](VALIDACION.md) y revisa las exportaciones modificadas.
